# README images

These are captures of Switch Magic 0.4.0’s QML interface, rendered in an isolated Wayland session
with fictional window titles, sample window previews, and workspace icon tiles.
They contain no personal desktop captures. The “Midnight gallery” view exists
only in the screenshot session; it is not shipped as a default.

Regenerate with `python scripts/screenshots.py`. The harness uses a fixed palette
and font, disables shortcut registration and desktop capture, and saves no settings.
Layout and Spaces images are 1440 × 900. Preferences images are 1100 × 850.
The light/dark wordmarks reuse the app’s vector icon geometry.
